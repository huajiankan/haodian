# 薅点 · Haodian

AI 积分，顺手薅点。macOS 菜单栏里的 AI 产品每日权益助手。

## 一键开薅，看看攒了多少

- **一键领取**：集中查看并领取豆包工作、WorkBuddy、Qoder CN 和 Qoder 国际版的每日权益，已领取的自动跳过。
- **累计收获**：查看通过薅点领取的权益参考价值、累计领取天数和最近 19 周的收获日历。
- **重启更新**：支持的客户端准备好更新后，一次操作重启更新，下次使用少等一步。
- **版本提醒**：定期检查薅点新版本，下载安装由你确认，也可右键点击菜单栏图标选择「检查更新...」。

实际权益与参与资格以各平台活动规则、账号及客户端连接状态为准。收获记录保存在本机，仅累计通过薅点领取并确认到账的权益；参考价值不代表现金或剩余额度。

## 下载与安装

下载 [薅点 0.8.5](https://github.com/huajiankan/haodian/releases/tag/v0.8.5) 中的 DMG，将「薅点」拖入「Applications」。完整功能介绍见该版本发布说明。

支持 macOS 13 及以上、Apple Silicon 和 Intel。当前使用临时签名，尚未经过 Apple 公证；首次打开可能需要在系统「隐私与安全性」中允许运行。

0.8.0 及之后版本支持应用内检查更新，更早版本请先手动安装新版。自动检查为内置行为，下载安装前仍由你确认。

本仓库用于分发安装包和更新文件。

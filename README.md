# 薅点 · Haodian

macOS 菜单栏里的 AI 产品每日权益助手。

支持查看豆包工作、WorkBuddy、Qoder CN 和 Qoder 的权益状态，并在符合条件时领取。实际可用权益取决于各产品账号、活动规则及客户端连接状态。

本仓库用于分发安装包和更新文件。

## 下载与安装

前往 [Releases](https://github.com/huajiankan/haodian/releases) 下载最新版本，将「薅点.app」放入「应用程序」文件夹后打开。

支持 macOS 13 及以上、Apple Silicon 和 Intel。当前为内测版本，使用临时签名，尚未经过 Apple 公证。

## 检查更新

从 0.8.0 起，右键点击菜单栏图标，选择「检查更新...」。默认每 12 小时自动检查，也可在同一菜单关闭「自动检查更新」。下载安装需用户确认。

旧版本需先手动安装 0.8.0 或之后版本，才能使用自动检查更新。
